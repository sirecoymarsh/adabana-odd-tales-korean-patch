# 도화이담 — 헛된 꽃의 기이한 이야기

『Adabana Odd Tales / 徒花異譚』 비공식 한국어 패치 **1.0**입니다.

## 다운로드와 설치

1. [Releases](https://github.com/sirecoymarsh/adabana-odd-tales-korean-patch/releases/latest)에서 `DohwaIdam_Korean_Patch_v1.0.zip`을 받습니다.
2. ZIP을 **새 폴더에 전부 압축 해제**합니다. `DohwaIdam_Korean_Patch_Setup.exe`와 `data` 폴더를 함께 두세요. 실행 파일만 따로 옮기면 설치 자료를 찾을 수 없습니다.
3. 게임을 종료하고 압축을 푼 폴더의 패처를 실행합니다.
4. 「자동 찾기」 또는 「찾아보기…」로 원하는 게임의 `GSIWin.exe`를 고른 뒤 「설치」를 누릅니다. 정식판과 체험판이 둘 다 있다면 선택된 폴더를 확인하세요.

기존에 받아둔 같은 이름의 구버전 실행 파일 대신, 이번 ZIP에 포함된 패처를 사용하세요. 자세한 사용법은 동봉된 `README_KO.txt`에 있습니다.

## 지원 범위

- 정식판 Build 5154306: Steam 설치본과 동일한 파일임을 확인했습니다. 판매처 이름이 아닌 게임 파일로 지원 여부를 판별합니다.
- Steam 체험판 Build 4878377: 서장과 제1권을 지원합니다. 체험판 전용 이미지 두 곳은 중국어로 남아 있습니다.
- 그 밖의 빌드는 아직 확인하지 않았으며, 지원하는 파일과 다르면 설치를 중단합니다.
- 게임 원본은 포함하지 않습니다. 정식판 이용에는 정품 게임이 필요합니다.
- 한국어는 간체 중국어 자리에 적용됩니다. 설치한 동안에는 간체 중국어를 쓸 수 없고 일본어·영어·번체 중국어는 유지됩니다.

## 추가·변경 사항

원판(『Adabana Odd Tales / 徒花異譚』 정식판·Steam 체험판)과 비교해 이 패치가 바꾸거나 더한 것입니다. 괄호 안은 근거(릴리스 태그, 배포 ZIP 안 파일 이름)입니다.

### 번역 범위

- **번역 원문**: 일본어 원문을 기준으로 옮겼습니다(배포 ZIP의 `README_KO.txt`). 음성은 일본어 그대로입니다.
- **시나리오 전체**: 서장부터 결말까지 본문 대사·서술과 선택지(장면 대본 `S00_01_CS.MAP` ~ `S05_12_CS.MAP` 등) (v1.0).
- **이름·화면 글자**: 인물 이름표(`NAME_CS.MAP`), 시스템 글(`SYSTEM_CS.MAP`), 메뉴·설정·저장/불러오기·백로그·스킵·대화 상자 같은 화면 그림(`CONFIG_*`, `SAVE`, `LOAD`, `SAVELOAD_P`, `BACKLOG*`, `SKIP`, `DIALOG*_CS.AKB` 등) (v1.0).
- **그림 글자**: 그림책(`BOOK_*`), 이벤트 그림·배경 속 글자(`EV*`, `BG*`, `EZ*_CS.AKB`), 장 제목 같은 글자 그림(`MOJI*.AKB`), 감상 모드 화면(`CGMODE*`, `MUSICMODE`, `BOOKMODE_P`)을 한국어로 다시 만들었습니다(v1.0).
- **영상 자막**: 오프닝(`OP.VSD`)과 두 엔딩(`END_UTUTU.VSD`, `END_YUME.VSD`) 영상에 가사 자막을 넣었습니다(v1.0).
- **글꼴**: 한글이 들어간 게임 글꼴(`FONT_ZEN_12PX`·`16PX`·`20PX`·`32PX.AKB`, `FONT_ZEN.MAP`)을 넣고, 게임 설정의 글꼴을 「Malgun Gothic」(맑은 고딕)으로 바꿉니다.
- **용어 「도화(徒花)」**: 원작에서 「아다바나」로 읽는 徒花를, 뜻이 전해지도록 한자어 「도화」로 적었습니다(이름으로 쓰일 때나 비유로 쓰일 때 모두). 작품 제목은 「도화이담」, 무대는 「도화향」, 「徒花荒らし」는 「도화 파괴자」로 옮겼습니다(`README_KO.txt`).
- **언어 자리**: 한국어는 게임의 간체 중국어 자리에 들어갑니다. 설치한 동안에는 간체 중국어를 쓸 수 없고 일본어·영어·번체 중국어는 그대로입니다.
- **체험판**: 서장과 제1권이 한국어로 나옵니다. 체험판에만 있는 그림 2장(체험판 끝의 발매 안내, 붉은 글씨가 적힌 그림책)은 중국어로 남아 있습니다.
- 패처 창 안에 시놉시스, 등장인물 원화, 「도화」 뜻 풀이, 모드 사용법 안내 탭이 있습니다(v1.0 릴리스 노트).

### 편의 기능 (정식판 모드)

정식판에는 게임 창 메뉴 막대에 「모드」 메뉴가 생깁니다. 실행 파일이 `dohwa-cheat.dll`을 불러와 동작합니다. 체험판에는 들어가지 않습니다.

- **선택지 플로우 차트**: 장면과 선택지를 한눈에 보고 원하는 곳으로 이동합니다. 읽은 장면만 열리고, 「전체 보기」를 켜면 아직 보지 않은 장면과 결말도 보입니다.
- **선택지 색깔 바꾸기**: 선택지 글자색으로 그 선택이 어느 결말로 이어지는지 보여 줍니다.
- **모든 콘텐츠 개방**: CG·음악·서책 감상 기록을 모두 엽니다. 개방하기 전 기록은 `dohwa-cheat-unlock-before.bin`에 보관합니다.
- **콘텐츠 개방 취소(개방 전 복원)**: 위 보관본으로 개방 전 감상 기록으로 되돌립니다.
- 모드 설정은 `dohwa-cheat.ini`에 저장됩니다.

### 화면 개선

- **한국어 줄바꿈 보정**: 한국어 문장이 어절 중간에서 끊기지 않도록 실행 파일 `GSIWin.exe`의 줄바꿈 처리를 고쳤습니다. 반각 문장부호(`. ! ) , ? ] }`)를 금칙 처리에 맞게 다루고, 줄 끝에서 낱말 단위로 넘기는지 검사합니다(`release_manifest.json`의 `exe_patch` 설명). 체험판에도 같은 보정을 체험판 주소에 넣었습니다.

### 설치·제거 방식

- **원본 판별**: 판매처 이름이 아니라 게임 파일(`GSIWin.exe`와 `.arc` 묶음 8개의 크기·SHA-256)로 판본을 가립니다. 정식판 Build 5154306(Steam 설치본과 같은 파일임을 확인)과 Steam 체험판 Build 4878377을 지원하며, 파일이 다르면 아무것도 바꾸지 않고 멈춥니다.
- **파일 추가 방식**: 게임의 `.arc` 묶음 파일은 건드리지 않고, 게임 폴더에 한국어 파일을 따로 넣습니다(정식판 270개·약 1.1 GB, 체험판 94개·약 394 MB).
- **실행 파일 고치기**: `GSIWin.exe`의 정해진 자리만 바꿉니다(정식판은 모드를 불러오는 `.cheat` 구역 추가 포함). 바꾸기 전후 SHA-256을 확인합니다.
- **설정 파일**: `Save\gsiwin.xml`에서 글꼴(Malgun Gothic)과 언어 두 값만 바꿉니다. 체험판 설정 파일에는 언어 항목이 없어서 한 줄을 넣고, 제거할 때 다시 뺍니다.
- **백업**: 원본은 게임 폴더 옆 「(게임 폴더 이름).DohwaIdam_Korean_Patch_Backup」 폴더에 보관합니다.
- **이전 패치 정리**: 이전 한국어 패치(v1.2.0, v1.3.0)가 설치되어 있으면 그것을 지우고 새로 설치합니다(예전 백업 폴더 이름 `..._Backup_v1.2.0`, `..._Backup_v1.3.0`도 알아봄).
- **실패 시 되돌리기**: 설치하다 멈추면 바꾼 것을 스스로 되돌립니다. 제거가 중단되어도 백업을 남겨 다시 시도할 수 있습니다.
- **검사·다시 설치**: 「검사」는 설치된 파일을 하나하나 확인하고, 「다시 설치」는 현재 모드 설정을 유지한 채 다시 넣습니다.
- **제거**: 한국어 파일과 모드(`dohwa-cheat.ini`, `cheat-debug.log` 등)를 지우고 실행 파일·글꼴·게임 언어를 원래대로 돌립니다. 설치 전부터 있던 같은 이름의 파일과 모드 설정은 백업에서 복원하고, 최종 제거 때는 최초 설치 전 설정으로 돌아갑니다. 세이브 데이터는 건드리지 않습니다.
- 게임이 Program Files 같은 곳에 있으면 관리자 권한을 물을 수 있습니다.

### 알려진 문제

- 체험판 전용 그림 2장(발매 안내, 붉은 글씨 그림책)은 중국어로 남아 있습니다.
- 정식판 Build 5154306과 체험판 Build 4878377 말고 다른 빌드는 확인하지 않았습니다. 게임이 업데이트되거나 파일 검사로 실행 파일이 바뀌면 한국어 줄바꿈과 모드 메뉴가 빠질 수 있으니 「다시 설치」를 누르세요.
- 설치한 동안 간체 중국어는 쓸 수 없습니다.
- 모드의 「전체 보기」와 콘텐츠 개방은 아직 읽지 않은 장면과 결말을 드러낼 수 있습니다. 개방을 되돌리려면 패치 제거 전에 게임에서 「콘텐츠 개방 취소」를 먼저 하세요.
- 설치 프로그램은 서명되지 않아 「Windows의 PC 보호」 창이 뜹니다.

## 검사와 제거

설치 시 한국어 줄바꿈 보정과 모드 적용을 위해 `GSIWin.exe`를 수정하고, 게임 설정의 글꼴과 언어를 변경합니다.

패처의 「검사」로 설치 파일을 확인하고, 「제거」로 패치 전 실행 파일·글꼴·언어 설정을 복원할 수 있습니다. 원본 백업은 게임 폴더 옆에 보관되므로 제거를 마칠 때까지 유지하세요. 패처는 세이브 데이터를 수정하지 않습니다.

모드의 콘텐츠 개방을 취소하고 싶다면 패치 제거 전에 게임에서 「콘텐츠 개방 취소」를 먼저 실행하세요.
